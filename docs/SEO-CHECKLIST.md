# SEO a indexácia VŠETKO24.sk

- Google Search Console: sitemap úspešne načítaná, 87 objavených URL (22. 10. 2026). Objavené URL nie sú automaticky indexované.
- `robots.txt` umožňuje prehľadávanie a uvádza sitemap.
- Cloudflare musí prepúšťať overený Googlebot aj po obnovení blokovania AI training crawlerov. Pravidlo Skip preskakujúce všetky managed rules je iba dočasné; po potvrdení bezpečného nastavenia ho odstrániť.
- Zjednotený názov značky v HTML title, OG a hlavičke na VŠETKO24.sk.
- Po nasadení overiť /robots.txt, /sitemap.xml, kanonické URL, odpovede HTTP 200 a Search Console Indexovanie > Stránky.
- Zmeny nasadiť až po explicitnom schválení.
