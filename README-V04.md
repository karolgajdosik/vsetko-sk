# VŠETKO24.sk 0.4 – prvých 15 praktických návodov

- 15 samostatných statických stránok v `/navody/[slug]/`.
- Vyhľadávanie na úvodnej stránke automaticky načíta nové témy zo `src/data/search.json`.
- Sitemap automaticky obsahuje všetky návody.
- Každá stránka má canonical, SEO metadáta a Article JSON-LD.
- Každá stránka odkazuje na príslušný oficiálny zdroj; konkrétne právne podmienky nie sú prezentované ako overené.
- Všetko funguje bez API, databázy a nových platených služieb.

Pred merge otestovať `npm run build`, vyhľadávanie, navigáciu a všetky odkazy.
